Make a good golf weekend happen.

The demo is a complete invented trip. A real shared event adds your own private configuration, an authenticated server and individual access links.

Start with the example

Use the demo identity menu to try the organizer and participant experiences. Explore proposals, enter scores, answer the poll and export a backup. After installation, the demo runs on your computer without provider calls.

Prepare your own event

  1. Read Make it yours. Copy the three example configuration files into a private directory and replace their invented content.
  2. Validate the complete configuration with the production build before people start saving. Keep your roster, photos, records and access links out of the public source.
  3. Follow Host a private event. Use a Node server behind HTTPS, initialize its private store, and give each person only their own participant link.

Working with an assistant?

Ask it to read skills/golf-trip-workshop/SKILL.md in the downloaded folder. The skill explains the product, private configuration and careful setup.
